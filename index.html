建立網路基準

把設備的 CLI 輸出一次貼上，產生一份可追溯、可檢查的網路現況基準。
  1. 收集每台 RouterOS 的輸出，合併成一個收集檔
    怎麼收集？指令清單與收集腳本

    推薦：在 WSL／Linux 執行收集腳本 ./tools/collect.sh devices.csv --output collection.txt，以 SSH 逐台收集並產生收集檔（用法見 README）。

    手動：在每台設備的終端機執行下列指令，把輸出存成一個檔案，每台設備前加一行「設備名 (管理 IP):」。格式範例在「建立基準」對話框的「格式說明」。

    
                
    
                
    
              
    
            
    2. 
            
  2. 按「建立基準」，貼上內容或選擇檔案
    3. 
            
  3. 在「檢查結果」看資料之間的矛盾與缺漏，點選後在圖上定位，在「詳細資料」看內容與原文在「檢查結果」看資料之間的矛盾與缺漏，點一下就在圖上定位；在圖上拖曳移動、雙指縮放，在「詳細資料」看內容與原文
    4.

        格式說明
        
每台設備以「設備名 (管理 IP):」開頭；每段輸出前是指令標記，可以是終端機的提示字元（[admin@設備名] > 指令）或 ### 指令。設備之間可以用一行底線（5 個以上）隔開，也可以省略。沒有設備標頭的檔案，以檔名當設備名。

        
TPE_CORE_RT_01 (10.1.10.2):
[admin@TPE_CORE_RT_01] > /system resource print
            version: 7.12.1 (stable)
         board-name: CCR2216-1G-12XS-2XQ
[admin@TPE_CORE_RT_01] > /ip neighbor print detail without-paging
 0 interface=sfp-sfpplus1 address=10.1.10.21 mac-address=74:4D:28:00:00:21 identity="TPE_ACC_SW_01" platform="MikroTik" interface-name="sfp-sfpplus1"
_____
TPE_ACC_SW_01 (10.1.10.21):
### /interface bridge host print detail without-paging
 0   D mac-address=00:11:22:33:44:55 vid=10 on-interface=ether5 bridge=bridge1
